# Contributing

Open an issue before changing public interfaces or formula rules. Create
a focused branch, add tests and roxygen documentation, run
`devtools::document()`, `devtools::test()`, and `devtools::check()`, and
submit a pull request. New scientific rules require a verified primary
reference and an entry in `development_notes/reference_audit.md`. Do not
add elements outside CHONPS to the 0.1.x series.
