# Changelog

## DOMformulaR 0.1.0

- Initial CHONPS-only release.
- Added peak-table import, validation, filtering, blank and replicate
  handling.
- Added negative-ion `[M-H]-` formula assignment with complete candidate
  retention.
- Added DOM formula indices, elemental and van Krevelen classifications.
- Added sample comparison, standardized exports, S3 workflow results,
  and ggplot2 visualizations.
- Added tests, vignettes, continuous integration, pkgdown configuration,
  and citation metadata.
