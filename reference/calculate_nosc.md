# Calculate nominal oxidation state of carbon

Uses elemental formal oxidation states H +1, O -2, N -3, S -2, and P +5.
Values are `NA` when C is zero or missing.

## Usage

``` r
calculate_nosc(data)
```

## Arguments

- data:

  Formula data frame.

## Value

Numeric NOSC vector.
