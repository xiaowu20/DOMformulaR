# Export standardized DOM results

Export standardized DOM results

## Usage

``` r
export_dom_results(x, path, format = tools::file_ext(path))
```

## Arguments

- x:

  A `dom_result` or data frame.

- path:

  Output file path.

- format:

  One of `csv`, `tsv`, `rds`, or `xlsx`.

## Value

The normalized output path, invisibly.
