# Public package file inventory

This inventory covers the intended public repository, not the surrounding Matlab project.

| Path | Role | Public release status |
|---|---|---|
| `R/` | Package functions for import, quality control, CHONPS assignment, metrics, comparison, plotting, and bounded extensions | Include |
| `man/`, `NAMESPACE` | Files generated by roxygen2 | Include |
| `tests/testthat/` | Simulated-data unit and workflow tests | Include |
| `inst/extdata/` | Simulated peak table and example YAML configuration | Include |
| `vignettes/` | Method, workflow, metric, visualization, and validation documentation | Include |
| `.github/` | R CMD check, coverage, lint, pkgdown, release checks, and contribution templates | Include after repository owner is confirmed |
| `DESCRIPTION`, `LICENSE*`, `README.md`, `NEWS.md`, `CITATION*`, `_pkgdown.yml`, `renv.lock` | Package and release metadata | Include after owner and author metadata are confirmed |
| `development_notes/*.md` | Audit and validation records | Include |
| `development_notes/run_local_validation.R` | Parameterized local validation script with no embedded private paths | Include |
| `development_notes/private_validation/` | Per-peak DXC comparison generated from unpublished local data | Exclude through `.gitignore` and `.Rbuildignore` |
| `DOMformulaR.Rcheck/`, `DOMformulaR_*.tar.gz`, `docs/` | Local build and site artifacts | Exclude or regenerate in CI |

No original Matlab source, manuscript PDF, DataAnalysis workbook, real DXC peak table, real molecular formula table, Zotero database, credential, access token, or absolute user path belongs in the public repository.
