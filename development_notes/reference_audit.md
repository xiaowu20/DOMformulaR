# Reference audit

| Method item | Verified source | What the source supports | Package use and limitation |
|---|---|---|---|
| Originating FTMSAnalysis workflow | Fu, Fujii, and Ma, 2023, DOI `10.1021/acs.analchem.2c04113` | Integration of FTMSCalibrate, Gaussian-based FTMSCombine alignment, and TRFu/FTMSDeu into the FTMSAnalysis workflow; SI documents Matlab source and formula-assignment conditions | Direct workflow provenance. DOMformulaR independently implements audited CHONPS formula-assignment and downstream-analysis behavior; it does not implement Gaussian FTMSCombine or full FTMSDeu |
| TRFu formula-assignment algorithm | Fu, Fujii, and Riedel, 2020, DOI `10.1016/j.aca.2020.05.048` | Development and benchmarking of TRFu and FuJHA for UHR-MS spectra of natural organic matter | Direct formula-assignment lineage; DOMformulaR uses an independent R implementation and project-validated parameterization rather than redistributed Matlab code |
| Automated formula assignment and homologous-series assistance | Kujawinski and Behn, 2006, DOI `10.1021/ac0600306` | Automated analysis of ultrahigh-resolution mass spectra and formula-assignment logic | Supports algorithmic context; package ranking is independently implemented and does not claim structure |
| Constrained CHONPS search, sub-ppm accuracy, DBE and chemical plausibility rules | Koch et al., 2007, DOI `10.1021/ac061949s` | Formula assignment with constrained elemental search and chemical rules | Supports the rule framework; project ranges and 0.75 ppm remain project-specific |
| Modified aromaticity index | Koch and Dittmar, 2006, DOI `10.1002/rcm.2386` | Formula-based aromaticity index for high-resolution organic-matter data | Used in `calculate_ai_mod()`; bonding and P/S interpretation remain uncertain |
| NOSC and carbon-oxidation energy relation | LaRowe and Van Cappellen, 2011, DOI `10.1016/j.gca.2011.01.020` | NOSC equation and empirical \(\Delta G^\circ_{\mathrm{Cox}}=60.3-28.5\,NOSC\) at 25 °C and 1 bar | Used as a formula-level standard-state proxy; not an in situ reaction Gibbs energy |
| Full R-based UHR-MS preprocessing and formula assignment | Schum, Brown, and Mazzoleni, 2020, DOI `10.1016/j.envres.2020.110114` | MFAssignR noise estimation, isotope filtering, recalibration, formula assignment, and ambiguity reduction | External comparison method; DOMformulaR does not import or claim MFAssignR algorithms |
| Standardized multispectrum processing | Merder et al., 2020, DOI `10.1021/acs.analchem.9b05659` | ICBM-OCEAN processing and alignment of ultrahigh-resolution spectra | External comparison method; not implemented |
| Interlaboratory reproducibility | Hawkes et al., 2020, DOI `10.1002/lom3.10364` | Instrumental and processing choices produce material interlaboratory differences in DOM HRMS results | Supports explicit parameter and evidence boundaries; not an algorithm dependency |
| R-based FT-MS exploration and visualization | Bramer et al., 2020, DOI `10.1371/journal.pcbi.1007654` | ftmsRanalysis data preparation, exploratory analysis, and interactive visualization | Related R software; DOMformulaR visualization code is independently implemented |
| Open-source NOM spectrum processing | Volikov, Rukhovich, and Perminova, 2023, DOI `10.1021/jasms.3c00003` | NOMspectra formula assignment, recalibration, descriptors, set operations, and visualization | Python comparison workflow; not implemented |
| False-positive exclusion by mass-error distributions | Gao et al., 2024, DOI `10.1021/acs.analchem.4c00489` | Uses mDa mass-error distributions and Kendrick-series relationships to resolve multiple assignments and detect false formulas | Strong candidate for future ambiguity control; current deterministic ranking does not implement this evidence model |
| Data-set-level assignment confidence | Dewey et al., 2025, DOI `10.1021/acs.analchem.4c06826` | Uses isotopologue similarity and cross-sample mass-error consistency to reduce false assignments | Strong candidate for multisample validation; not implemented |

The previously entered DOI `10.1016/j.gca.2010.11.034` was invalid and was corrected after checking the original article. The correct paper is *Degradation of natural organic matter: A thermodynamic analysis*, *Geochimica et Cosmochimica Acta* 75, 2030–2042.

No package default should be described as a universal literature default. Mass tolerance, atom ranges, signal-to-noise threshold, and ranking weights require instrument-, calibration-, and project-specific validation.
